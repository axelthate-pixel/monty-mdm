# 🛠️ Citizen Developer – Streamlit Template

> Startpunkt für eigene Tools ohne Programmiererfahrung  
> Teil der **Techem Citizen Developer Plattform**

---

## In einer Minute starten

1. Klicke oben auf **„Use this template" → „Create a new repository"**
2. Gib deinem Repo einen Namen (z. B. `mein-tool`)
3. Klicke auf **„Create repository"**
4. Klicke dann auf **„Code" → „Codespaces" → „Create codespace on main"**
5. Warte ~2 Minuten (Umgebung wird automatisch eingerichtet)
6. Im Terminal: `streamlit run app.py`
7. Öffne `GETTING_STARTED.md` für die nächsten Schritte

**Keine Installation. Keine Programmiererfahrung nötig.**

---

## Was dieses Template enthält

| Datei / Ordner | Inhalt |
|---|---|
| `app.py` | Leere Streamlit-App – hier baust du dein Tool |
| `requirements.txt` | Python-Abhängigkeiten (Streamlit, pandas) |
| `.devcontainer/` | GitHub Codespaces Konfiguration (Python 3.12 + Copilot) |
| `.github/` | Dependabot + Auto-Merge Workflow |
| `GETTING_STARTED.md` | Deutsche Schritt-für-Schritt-Anleitung + Copilot-Prompts |

---

## Dieses Repo als GitHub Template einrichten

Damit andere Mitarbeitende das Template per Klick nutzen können:

1. Gehe in GitHub zu **Settings** deines Repos
2. Aktiviere die Checkbox **„Template repository"**
3. Fertig – das Repo erscheint jetzt mit dem Button „Use this template"
