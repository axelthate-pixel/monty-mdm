# Copilot Instructions – Techem Citizen Developer Plattform

## Projektkontext
Ich nutze das **citizen-dev-streamlit-template** der Techem Citizen Developer Plattform,
um ein eigenes Tool mit KI-Unterstützung zu bauen.
Ziel ist es, Mitarbeitern ohne Programmiererfahrung zu ermöglichen, nützliche Werkzeuge zu entwickeln.

## Tech Stack
- Python 3.12
- Streamlit (UI-Framework)
- GitHub Codespaces (Entwicklungsumgebung)
- GitHub Actions (Automatisierung)
- Dependabot (Dependency-Updates)

## Arbeitsweise
- Alle Erklärungen und Kommentare auf Deutsch
- Code-Kommentare auf Englisch
- Immer vollständige Dateien liefern, keine Ausschnitte
- Schritt für Schritt vorgehen, auf Bestätigung warten
- Keine komplexen Architekturen – einfach, verständlich, wartbar

## Hinweise für Copilot
- Die Hauptdatei ist `app.py`
- Neue Python-Pakete müssen in `requirements.txt` eingetragen werden
- Streamlit-Komponenten bevorzugen (`st.dataframe`, `st.form`, `st.download_button` usw.)
- Keine externen Dienste ohne ausdrückliche Anforderung einbinden
